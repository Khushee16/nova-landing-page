# Nova — Analytics for Modern Teams

A polished, fully responsive SaaS landing page for a fictional analytics product called Nova. Built to demonstrate modern marketing-site craft: smooth animations, thoughtful interactions, and a clean component-style structure — all with zero frameworks.

## Features

- Sticky header with mobile hamburger menu and scroll shadow
- Hero with animated gradient blobs and a pure-CSS dashboard mockup
- Scroll-reveal animations via IntersectionObserver
- Dark / light mode toggle, persisted in localStorage (respects OS preference)
- Monthly/yearly pricing toggle with animated price swaps
- Testimonial carousel with autoplay, arrows, dots, and pause-on-hover
- FAQ accordion (one open at a time)
- Contact form with client-side validation and success state
- Animated stat counters, responsive at 960px / 640px breakpoints

## Tech

HTML, CSS (custom properties, flexbox/grid), vanilla JavaScript. No frameworks, no build step — just open `index.html`.
